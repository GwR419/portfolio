The window object is the browser window (or tab) itself. It is the top level of everything JavaScript can see in the browser. The document is a property of the window, and it holds the actual HTML page that got loaded into it. So window.document and document point to the same thing.

An event is something that happens on the page, like a click, a key press, or the page finishing loading. The target is the element the event happens to. The event handler is the function that runs when the event happens.

addEventListener() connects an event to a function. It takes the event name (like 'click'), the function to run, and false at the end. You give it the function name without the parentheses, otherwise the function runs right away instead of waiting for the event.

window.onload waits for everything on the page to load, images included. DOMContentLoaded fires as soon as the HTML has been read, so it starts sooner. Either way the point is the same: the script waits for the page to exist before it tries to find elements on it. That is why my init() function runs on DOMContentLoaded.

document.getElementsByTagName('button') gives back a list of every button on the page. Unlike XPath, JavaScript counts from 0, so the first button is buttons[0] and the last one is buttons[buttons.length - 1].
